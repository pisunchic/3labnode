# CLI Tasks

CLI инструмент для решения задач с поддержкой потоковой обработки данных.

## Установка

```bash
npm install
```

## Использование

Программа может быть запущена следующими способами:

1. Через npm:
```bash
npm start -- [опции]
```

2. После глобальной установки:
```bash
npm install -g .
cli-tasks [опции]
```

### Опции

Программа поддерживает следующие опции:

- `-i, --input <путь>` - путь к входному файлу (опционально)
- `-o, --output <путь>` - путь к выходному файлу (опционально)
- `-t, --task <название>` - название задачи (обязательно)
- `-f, --format <формат>` - формат входных данных (string, array, json) (по умолчанию: string)
- `-d, --delimiter <символ>` - разделитель для множественных параметров (по умолчанию: :)

### Основные сценарии использования

1. Чтение из файла и запись в файл:
```bash
cli-tasks -i "./input.txt" -o "./output.txt" -t task1
```
Данные считываются из файла, преобразуются, результат записывается в файл.

2. Чтение из файла и вывод в консоль:
```bash
cli-tasks -i "./input.txt" -t task1
```
Данные считываются из файла, преобразуются, результат выводится в консоль.

3. Чтение из консоли и запись в файл:
```bash
cli-tasks -o "./output.txt" -t task1
```
Данные считываются из консоли, преобразуются, результат записывается в файл.

4. Чтение из консоли и вывод в консоль:
```bash
cli-tasks -t task1
```
Данные считываются из консоли, преобразуются, результат выводится в консоль.

### Форматы входных данных

1. Строковый формат (по умолчанию):
```bash
# Один параметр
echo "text" | cli-tasks -t task1

# Несколько параметров (разделенных двоеточием)
echo "text1:text2" | cli-tasks -t task1
```

2. Массив:
```bash
# Один массив
echo "[1, 2, 3]" | cli-tasks -t task1 -f array

# Несколько массивов
echo "[1,2,3]:[4,5,6]" | cli-tasks -t task1 -f array
```

3. JSON:
```bash
# Любой валидный JSON
echo '{"key": "value"}' | cli-tasks -t task1 -f json
```

### Особенности

- Если входной файл не указан, программа читает данные из stdin (консоли)
- Если выходной файл не указан, программа выводит результат в stdout (консоль)
- При чтении из консоли программа продолжает работу после выполнения задачи
- При ошибках (несуществующий файл, проблемы с правами доступа и т.д.) выводится сообщение об ошибке в stderr
- Программа использует потоковую обработку данных для эффективной работы с большими файлами
- Поддерживаются различные форматы входных данных (строки, массивы, JSON)
- Можно указать пользовательский разделитель для множественных параметров
- Результат автоматически преобразуется в строку (если это не строка, используется JSON.stringify)
